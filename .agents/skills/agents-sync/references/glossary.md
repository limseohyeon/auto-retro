# Translation Glossary

Use these terms consistently. Preserve code identifiers and quoted product names exactly.

- 에이전트 규칙: agent rules
- 중앙 통제 및 위임: central control and delegation
- 실행 계획: execution plan
- 개발 기록: development record
- 주간 회고: weekly retrospective
- 발표 초안: presentation draft
- 사용자: user
- 입력 어댑터: inbound adapter
- 출력 어댑터: outbound adapter
- 애플리케이션 포트: application port
- 모듈 경계: module boundary
- 불변조건: invariant
- 생성물: generated artifact
- 원본: source of truth
- 동기화: synchronization
- 검증: verification

Translate normative language without weakening it:

- 반드시, 해야 한다: must
- 절대 하지 않는다: never, must not
- 권장한다: should
- 할 수 있다: may
