# AI 엔지니어링 로드맵

## 현재 진단

저장소에는 기술·아키텍처 규칙, Spring Modulith 경계 테스트, Flyway 마이그레이션, 백엔드 CI가 이미 있었다. 그러나 제품 문서 링크가 깨져 있었고, 프런트 검증은 CI에 없었으며, 로컬과 CI가 공유하는 전체 검증 명령과 장기 작업 인계 형식이 없었다.

초기 목표는 규칙의 양을 늘리는 것이 아니라 coding agent가 현재 상태를 빠르게 찾고, 작은 기능을 구현하고, 같은 검증 결과를 재현할 수 있게 만드는 것이다.

- [x] 필수 문서와 로컬 Markdown 링크를 검사하는 테스트 추가

## 실제 개발 중 발전시킬 항목

- [ ] coding agent의 반복 실수와 리뷰 수정 사항을 이슈나 실행 계획에 기록
- [ ] 같은 문제가 두 번 이상 발생하거나 손실 비용이 크면 자동 검사 또는 규칙으로 승격
- [ ] 모듈마다 명령이나 제약이 달라질 때만 하위 `AGENTS.md` 추가
